# Elliott Dinner Planner

Freshness-aware, offline-capable fortnight dinner planner built around the actual ALDI/DoorDash grocery shop.

## Features
- Dynamic meal ranking based on freshness, inventory and freezer state
- Required recipe ingredients are restricted to purchased groceries
- Optional pantry suggestions are clearly labelled and never deducted
- Persistent IndexedDB memory between sessions
- Protein portion/freezer manager
- Step-by-step Cook Mode with timers
- Inventory deductions, waste tracking, ratings and history
- DoorDash-friendly next-shop generator
- Offline PWA with iPhone Home Screen support

## First setup
The chicken pack starts at an estimated 1.38 kg and beef at 1.9 kg. Open **Stock** and replace these with the delivered label weights. Chicken portions automatically recalculate to one sixth of the actual pack.

## iPhone
Open the GitHub Pages URL in Safari, then **Share → Add to Home Screen**.
